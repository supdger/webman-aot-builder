## Purpose

让项目使用者在 Windows 构建时可恢复短暂目录占用，并在无法激活项目镜像时获得明确的底层原因，避免影响原始源码、其他构建目录及已有产物。

## ADDED Requirements

### Requirement: 有限目录激活恢复
系统 SHALL 在镜像目录激活出现可重试失败时进行有限重试，并保留原项目、一致性检查和构建隔离；永久失败 MUST 保留失败退出码及系统原因。

#### Scenario: 短暂失败恢复
- **WHEN** 激活首次失败随后目录可用
- **THEN** 构建激活完整镜像并继续

#### Scenario: 持续失败
- **WHEN** 激活在有限重试内持续失败
- **THEN** 输出失败操作、路径及系统原因，不发布不完整产物

### Requirement: 激活不得覆盖冲突目标
系统 MUST 拒绝既有目标、符号链接或构建目录归属异常，不得在恢复过程中覆盖其他写者的数据。

#### Scenario: 目标冲突
- **WHEN** 激活期间目标已被另一写者创建
- **THEN** 停止激活，保留目标，报告冲突
